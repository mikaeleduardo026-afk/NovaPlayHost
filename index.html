CONFIGURAÇÃO INICIAL

Prepare sua chave de assinatura.

Este painel cria e protege uma chave Ed25519 para emitir tokens do ScriptLab SA, Lumora e MTA Asset Viewer. A chave privada será cifrada com uma senha escolhida por você e guardada somente neste navegador.

Criar cofre administrativo

Use uma senha forte e exclusiva. Ela protege a chave privada que assina todos os tokens emitidos por este painel.

A chave privada não será exibida no código-fonte. Faça o backup cifrado assim que terminar a configuração.

ACESSO ADMINISTRATIVO

O cofre de assinatura está configurado. Desbloqueie-o para emitir licenças digitais.

Desbloquear cofre

A senha descriptografa a chave privada localmente. Ela não é enviada a nenhum servidor.

ADMINISTRAÇÃO · EMISSÃO DE LICENÇAS

Gerador de tokens.

Escolha o produto e crie códigos individuais assinados para o ScriptLab SA, Lumora ou MTA Asset Viewer. Cada token fica vinculado ao produto selecionado e não funciona nos outros.

Emitir novos tokens

Todos os planos usam o mesmo formato de token, com os dados do plano protegidos por assinatura digital Ed25519.

● Cofre desbloqueado
Próximo passo: mantenha esta chave pública configurada nos três produtos: ScriptLab SA, Lumora e MTA Asset Viewer. A chave privada deve permanecer apenas no cofre administrativo.
Limites de segurança desta versão: o painel assina tokens no navegador e protege a chave privada com uma senha. Não publique este painel para o público. O portal principal ainda usa armazenamento local: o uso único do token não é compartilhado entre dispositivos e a expiração não é imposta por um servidor central. Para controle real de resgate, revogação e contas, é necessário um backend.
