MÓDULO 01 · FUNDAMENTOS

O que é um resource?

No MTA:SA, um resource é uma unidade organizada de arquivos que o servidor pode iniciar, parar e administrar. Ele pode conter scripts Lua, arquivos de configuração, imagens, modelos e outros recursos utilizados pelo projeto.

1. O arquivo meta.xml

O meta.xml informa ao MTA quais arquivos fazem parte do resource e como eles devem ser carregados. Neste exemplo, vamos declarar um arquivo Lua executado no cliente.

<meta> <info author="SeuNome" name="Meu Primeiro Resource" version="1.0" /> <script src="client.lua" type="client" /> </meta>

2. O arquivo client.lua

Agora criamos o arquivo client.lua. O comando abaixo registra /ola. Quando o jogador executar o comando, uma mensagem será exibida no chat local.

addCommandHandler("ola", function() outputChatBox("Olá, mundo! Meu primeiro script.") end)
Conceito importante: scripts do tipo client executam no computador do jogador. Scripts do tipo server executam no servidor. Essa diferença será aprofundada na trilha de MTA:SA.

3. Confira o que você aprendeu
